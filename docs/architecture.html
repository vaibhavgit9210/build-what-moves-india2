Why these choices
No backendA judge can click the whole journey with nothing running. In a demo about crime victims, storing zero real data is the feature.
Keyless by defaultThe intake works for a stranger with no API key and no budget. gpt-oss is open weight, so Workers AI serves it free.
Statutes in a contract fileA wrong section of law is worse than no section. Types and a single lookup make a category losing its statutes impossible.
Whisper on deviceVoice matters for people who cannot type a formal complaint. A description of a crime should not travel to be transcribed.
